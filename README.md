# Little Notes

A cheerful, local-first notes app built with React and Vite. Notes stay in this browser's local storage.

## Run it

Install [Node.js](https://nodejs.org/), then run:

```sh
npm install
npm run dev
```

Use **New note** to add a note. Click a note to edit it, pin it to keep it at the top, or search across titles and text. Notes are stored in local storage on this device and are not synced elsewhere.
